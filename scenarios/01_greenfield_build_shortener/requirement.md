# Scenario 1 (Greenfield): Build a URL Shortener

Type: greenfield

We need a URL shortener service built from scratch. Users should be able to
submit a long URL and get back a short one. Visiting the short URL should
take them to the original page. We also want basic click analytics per
short link (how many times it's been visited, when it was last visited).

No existing codebase -- this is a brand new service.
